KANCELARIA TAX MAREK CHACHOWSKI — PAKIET STRONY WWW

ZAWARTOŚĆ
- index.html — strona główna
- style.css — styl i responsywny układ
- script.js — menu mobilne i demonstracyjny formularz mailowy
- polityka-prywatnosci.html — roboczy szablon do uzupełnienia

PRZED PUBLIKACJĄ
1. Otwórz index.html i wyszukaj: TU_WPISZ_EMAIL, TU_WPISZ_NUMER, TU_WPISZ_ADRES.
2. Telefon i e-mail zostały uzupełnione zgodnie z przekazanymi danymi. Adres kancelarii pozostawiono bez ulicy — strona informuje o obsłudze klientów z całej Polski.
3. Zweryfikuj, które usługi kancelaria faktycznie świadczy, oraz popraw opisy.
4. Uzupełnij polityka-prywatnosci.html zgodnie z rzeczywistym przetwarzaniem danych. To nie jest porada prawna.
5. Sprawdź dane firmy, wymagane informacje prawne i ewentualne uprawnienia/ubezpieczenie przed publikacją.
6. Obrazy są ładowane z Unsplash, a fonty z Google Fonts — do działania potrzebny jest internet. Możesz podmienić adresy zdjęć w style.css.

BEZPŁATNA PUBLIKACJA — GITHUB PAGES
1. Zaloguj się lub utwórz konto na github.com.
2. Utwórz nowe repozytorium, np. kancelaria-tax-strona. Dla najprostszej publikacji może być publiczne.
3. Wgraj wszystkie pliki z tego folderu (index.html musi być w katalogu głównym repozytorium).
4. Wejdź w Settings → Pages.
5. W sekcji Build and deployment wybierz Deploy from a branch, branch: main, folder: /(root), a następnie Save.
6. Po zakończeniu publikacji GitHub pokaże adres w formacie https://NAZWA-UZYTKOWNIKA.github.io/kancelaria-tax-strona/
7. Aktualizacje publikujesz przez wgranie zmienionych plików do repozytorium.

KOSZT
- Hosting GitHub Pages: bez opłat dla typowego statycznego projektu w publicznym repozytorium.
- Adres w domenie github.io: bez opłat.
- Własna domena .pl/.com: opcjonalna, płatna; przy budżecie do 100 zł sprawdź cenę rejestracji i odnowienia u rejestratora.
- Formularz: obecnie otwiera program pocztowy użytkownika (mailto), nie przechowuje ani nie wysyła danych na serwerze. Właściciel musi podmienić placeholder e-mail.
